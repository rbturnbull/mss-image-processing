# Practical Image Processing for Manuscripts on the Command Line

This is a Quarto website version of the conference paper/tutorial.

## Preview locally

```bash
quarto preview
```

## Render

```bash
quarto render
```

The rendered website will be written to `docs/`, as configured in `_quarto.yml`.

## Publish on GitHub Pages

1. Push this repository to GitHub.
2. Run `quarto render` locally, or use a GitHub Actions workflow to render it.
3. In the repository settings, enable GitHub Pages and choose the `docs/` folder on the main branch.
